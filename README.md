# QX Media brand and website

**An Arabic-first digital presence for a Riyadh marketing agency.**

[Live site](https://qxmedia.sa/) · [Portfolio](https://tarek-portfolio-phi.vercel.app/#brands)

## The project

QX Media presents strategy, brand identity, campaigns, content, search, and social media services for Saudi and Gulf clients. The work represented here joins the agency's visual language with a custom WordPress theme designed for Arabic and English content.

## Design and build

- Editorial layouts that use the agency's restrained palette and typography.
- Right-to-left Arabic presentation with English support.
- Custom templates for the home page and core service pages.
- A scroll-driven 3D hero implemented as source modules with a separately built bundle.
- Responsive navigation, page components, and theme configuration without a page builder.

The local theme source supports these implementation details. Marketing figures and testimonials on the live website are not independently verified by this repository.

## Repository contents

`source/qx-theme/` contains selected, reviewed PHP, CSS, JavaScript, and JSON source from the local theme. Contact flows and marketing content, font binaries, brand images, vendor libraries, the generated 3D bundle, WordPress itself, and production data are excluded. This is a source review package, not a ready-to-install copy of the live site.

## العربية

يقدم المشروع هوية QX Media الرقمية وموقعها الموجه للجمهور السعودي والخليجي. يحتوي المستودع على دراسة حالة وشيفرة قالب WordPress التي أمكن مراجعتها محليًا. لا يشمل الخطوط أو الصور أو مكتبات الطرف الثالث أو بيانات الموقع الفعلي.
